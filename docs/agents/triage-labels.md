# Triage labels

Five canonical roles, written as a `Status:` line at the top of each issue file:

| Label | Meaning |
|-------|---------|
| `needs-triage` | Not yet looked at; default for a new issue. |
| `needs-info` | Blocked on a question for the reporter. |
| `ready-for-agent` | Clear enough for an agent to implement unattended. |
| `ready-for-human` | Needs human judgement, access, or a real API key. |
| `wontfix` | Deliberately not doing it; record why in the body. |

Only one status per issue. Change it by editing the line, not by adding a
second one.
